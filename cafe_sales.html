01

Cafe Business Sales Performance Analysis

This project focused on analyzing cafe transaction data to understand sales performance and customer purchasing behavior. The data was explored and transformed into meaningful visual insights using Python and Tableau. The analysis covered product performance, purchasing patterns, payment methods, spending levels, and transaction activity.

ROLE Data Analyst · Business Intelligence · Data Visualization
TOOLS Python · Tableau
DATASET Cafe Transaction Data
OUTPUT Interactive Tableau Dashboard
02

Process

The project followed a data analysis workflow to transform raw cafe transaction data into structured information and visual insights for understanding sales performance and customer purchasing behavior.

01
DATA SOURCE

Cafe Transaction Data

The project started with cafe sales transaction data containing information related to products, transaction activity, purchase quantity, spending, and payment methods.

02
PYTHON · DATA PREPARATION

Data Cleaning & Preprocessing

The dataset was prepared using Python before the analysis. The data preparation process focused on improving data quality and ensuring that the transaction data was ready for further analysis and visualization.

03
PYTHON · DATA ANALYSIS

Exploratory Data Analysis

Exploratory analysis was performed to understand patterns across product categories, purchase quantities, spending levels, transaction activity, and payment methods.

04
PYTHON · VISUALIZATION

Data Visualization

Python was also used to visualize the analyzed data and support the exploration of sales and customer behavior. Visual representations helped identify patterns before developing the final interactive dashboard.

05
TABLEAU · DATA VISUALIZATION

Interactive Dashboard

The processed and analyzed data was presented through Tableau. Interactive dashboards were developed to explore overall sales performance, transaction trends, product performance, customer behavior, and payment method distribution.

06
BUSINESS ANALYSIS

Sales Performance Analysis

The final analysis was used to identify meaningful sales and purchasing patterns across products, transaction periods, spending levels, and payment methods. These findings provided a clearer view of cafe business performance and customer purchasing behavior.

03

Dashboard

The interactive Tableau dashboard presents the analyzed data through three main views, allowing users to explore sales performance, customer purchasing behavior, and revenue patterns.

View Interactive Tableau Dashboard →
01

Business Overview

Provides an overview of cafe sales performance, including total revenue, transaction activity, top-selling products, revenue per item, monthly transaction trends, and payment method distribution.

02

Relationship Analysis

Explores relationships between customer purchasing behavior, transaction activity, spending levels, product categories, and other sales-related dimensions to identify purchasing patterns.

03

Revenue Analysis

Focuses on revenue performance across products and transaction periods to identify differences in sales contribution and purchasing activity.

04

Key Insights

The analysis identified differences in sales performance across product categories, with several products contributing more strongly to overall sales and transaction volume. The dashboard also revealed patterns in monthly transaction activity and customer spending behavior, providing a clearer view of how purchasing activity varied across the analyzed period.

Payment method analysis showed differences in transaction distribution across payment types, while the relationship analysis helped highlight purchasing patterns across customers and products. These findings were visualized through Tableau to support a more structured understanding of cafe business performance and customer behavior.
