Process

The project followed a big data and predictive analytics workflow to transform Brazilian e-commerce transaction data into analytical insights about customer satisfaction.

01
DATA SOURCE

Brazilian E-Commerce Data

The project used the Brazilian Public E-Commerce dataset containing transaction, customer, order, payment, review, product, seller, and geographic information.

02
PYTHON · DATA PREPARATION

Data Preparation

Python and Pandas were used to clean and prepare the CSV data before further processing within the big data environment.

03
HDFS · HADOOP

Distributed Data Storage

The prepared datasets were loaded into HDFS within a Cloudera virtual machine environment to support distributed storage and processing.

04
SPARK · PYSPARK

Data Processing

Apache Spark was used for distributed data processing, transformation, feature preparation, and analytical workloads.

05
PREDICTIVE MODELING

Customer Satisfaction Prediction

Predictive modeling was performed using transaction and delivery-related variables, including delivery time, late delivery, order quantity, and delivery cost.

06
POWER BI · BUSINESS INTELLIGENCE

Dashboard & Analysis

The analytical results were presented through an interactive Power BI dashboard covering customer satisfaction, delivery performance, order complexity, and regional patterns.

05

Key Insights

The analysis showed that delivery-related factors were strongly associated with customer satisfaction. Delivery time, late delivery, order quantity, and delivery cost were among the factors identified through the analysis. The predictive modeling stage achieved an accuracy of 81.98%, while the feature analysis highlighted the importance of logistics and delivery performance in understanding customer satisfaction.

The dashboard also highlighted patterns in delivery performance, regional activity, and order complexity. These results were presented through Power BI to provide a more structured view of customer satisfaction and logistics performance within the Brazilian e-commerce dataset.
